Introduction

Everything you need to get blaid running well in your server.

blaid is an all-in-one Discord app: moderation and security, leveling, tickets, VoiceMaster, giveaways, Last.fm, and a growing set of automation tools, all in one bot. It's built to replace several single-purpose bots with one consistent, well-documented one.

Every command on this site is pulled directly from the bot's own code, so what you see here always matches what's actually running - nothing here is hand-written documentation that can drift out of date.

Run ,help in your server for an interactive command list, or browse everything with search on the Commands page.

Server Setup

Run ,setup with Administrator permissions. This is the one command that needs to happen before most moderation features will work. It creates:

A jailed role and a jail channel only that role can see, a dedicated logs channel that every moderation action gets reported to, and a category that holds both of those channels so they stay organized and out of the way of your regular channels.

blaid's own role has to sit above every role it needs to manage - the jailed role included. If setup can't finish because of that, it tells you exactly which role to drag blaid above in Server Settings, then you just run ,setup again.

Made a mistake or want to start over? ,setup reset tears everything back down cleanly: it unjails anyone currently jailed, deletes the jail role, and removes the channels and category, so you can run ,setup fresh.

Permissions

Most commands check for a real Discord permission (Manage Guild, Ban Members, Manage Roles, and so on) before running - whichever permission a command needs is shown on its card on the Commands page.

Sometimes you want a role to be able to use a specific blaid command without handing out the real, powerful Discord permission that command normally requires - a moderator role that can use ,ban without actually having server-wide Ban Members, for example. ,fakepermissions lets you grant that on a per-role, per-permission basis, just for blaid.

You can also disable individual commands per server with ,disable - server-wide, or scoped to a specific channel or role - and bring them back with ,enable.

Prefixes

The default prefix is ,. Server admins can change the server-wide prefix, and any member can additionally set their own personal prefix that works for them specifically in every server blaid is in - handy if the server prefix clashes with another bot you use.

Moderation

The full toolkit: bans (including a hardban that also deletes recent message history, and a softban that bans-then-unbans purely to clear messages), kicks, timeouts, warnings with a full history you can review later, and jail - a role-based mute that removes access to the whole server except one channel, for when a timeout isn't enough but a ban is too much.

Every action - who did what, to whom, and why - is written to your configured logs channel automatically, with a running case number so nothing gets lost.

Antinuke & Antiraid

Antinuke watches for the exact patterns a compromised admin account or a malicious bot uses to destroy a server fast - mass channel deletion, mass banning, webhook abuse, dangerous permission grants - and can strip roles, kick, or ban the account responsible before real damage is done, all with thresholds you control.

Antiraid is the join-side counterpart: it looks at mass joins, brand new accounts, default avatars, and suspicious username patterns to catch a coordinated raid as it's happening, not after.

Tickets

Set up a ticket panel with ,tickets panel, customize the questions members answer when opening one, and route different ticket types to different categories. Staff claim, close, reopen, and delete tickets right from buttons on the channel itself, and every closed ticket can generate a transcript automatically.

Leveling

Members earn XP from chatting and level up over time. Configure the level-up message, assign role rewards at specific levels, and - with Server Premium - customize the level-up card's look for your server.

VoiceMaster

Join-to-create voice channels: members joining your hub channel get their own temporary voice channel they fully control - lock it, rename it, set a user limit, or hand ownership to someone else - all through buttons on a control panel, no commands to memorize.

Last.fm

Link a Last.fm account with ,lastfm set, then check what you're currently playing with ,fm, browse your top artists, albums, and tracks, compare taste with friends, and see who in the server has played a given artist the most.

Giveaways

Start a giveaway with a duration, a winner count, and an optional role requirement to enter. blaid picks winners automatically when it ends, and you can reroll a winner at any time if needed.

Automation

Autoresponders reply automatically to trigger words, autoreacts add reactions to messages containing a keyword, join DMs welcome new members in their DMs, and scheduled messages post - once or on a repeating interval - without you needing to be there to send them.

Plans & Billing
