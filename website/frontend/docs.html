Introduction

Everything you need to get blaid running well in your server.

blaid is an all-in-one Discord app: moderation and security, leveling, tickets, VoiceMaster, giveaways, Last.fm, and a growing set of automation tools, all in one bot.

Run ,help in your server for an interactive command list, or browse everything with search on the Commands page.

Server Setup

Run ,setup with Administrator permissions. This creates a jail role and channel, a logs channel, and the category that holds them - the minimum blaid needs before moderation commands like ,jail or ,ban will work.

blaid's own role has to sit above any role it needs to manage. If setup can't finish, it'll tell you exactly which role to drag it above.

Permissions

Most commands check for a real Discord permission (Manage Guild, Ban Members, and so on) before running - shown under "Permissions" on each command's card. You can also grant a role permission to use a gated command without giving them the real Discord permission, via ,fakepermissions.

Moderation

Bans, kicks, timeouts, warnings, jail, and a full antinuke/antiraid system that watches for mass bans, webhook spam, and suspicious joins. Every action is logged to your configured logs channel automatically.

Tickets

Set up a ticket panel with ,tickets panel, customize the questions members answer when opening one, and claim/close/transcript them from buttons right on the ticket channel.

Leveling

Members earn XP from chatting. Set level-up messages, role rewards per level, and (with Server Premium) customize the level-up card itself.

VoiceMaster

Join-to-create voice channels: members get their own temporary channel they can lock, rename, or hand off, with buttons for the whole flow.

Plans & Billing

blaid has two independent premium plans - see the full breakdown, pricing, and what each one unlocks on the Premium page. Run ,premium in your server any time to buy or manage a plan.
