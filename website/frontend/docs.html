Introduction

Everything you need to get blaid running well in your server.

blaid is an all-in-one Discord app: moderation and security, leveling, tickets, VoiceMaster, giveaways, Last.fm, and a growing set of automation tools, all in one bot.

Quick start

Invite blaid to your server, then run ,setup with Administrator permissions. This creates the jail role and channel, a logs channel, and the category that holds them - the minimum blaid needs before moderation commands like ,jail or ,ban will work.

Finding a command

Run ,help in your server for an interactive list, or browse every command with search and examples on the Commands page.

Getting help

Join the support server from the menu in the top right if you get stuck - someone's usually around.
